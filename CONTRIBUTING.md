# Contributing

Thank you for helping improve Hieroglyph OCR. Please open an issue before large changes so the proposed direction can be discussed.

Create a virtual environment, install development dependencies with `pip install -e ".[dev]"`, run `ruff check .`, and run `pytest -q` before opening a pull request.

Please do not commit model weights, API keys, private images, or datasets whose licenses do not permit redistribution. Large model artifacts should remain in the Hugging Face model repository.
